# Ludo Royale

## Run locally

1. Install Node.js v18 or newer.
2. Open a terminal in the project folder.
3. Run `npm install`.
4. Run `npm start`.
5. Open http://localhost:3000 in your browser.

To play with friends on the same Wi-Fi, open `http://<your-PC-IP>:3000` on their devices.

The app uses Express and Socket.IO. For online play across different networks, deploy the Node.js server to a public hosting provider.
